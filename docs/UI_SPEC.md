# Agent Relay 桌面交互规格

版本：0.1.0-preview.10。Windows WPF 四页界面，中文使用微软雅黑字体；协议标识和用户路径不做翻译。

| 页面 | 职责 |
| --- | --- |
| 任务看板 | 文件交接创建、明确的当前等待者、短提示、状态与处理记录 |
| Agent 管理 | 自选名称、资料解析或接口填写、安装/移除按需规则、CLI 探针 |
| 连接图 | 每对节点一条线，方案方向及独立开关 |
| 设置 | 中转站、保留期、通知、外观、高级 CLI 扩充和移除全部规则 |

## 新建文件交接

主要入口是粘贴 `{from,to,file,message?}` 后“解析并创建交接”，也可手动选择节点与已存在文件。点击即明确创建本地任务，未操作前不创建。当前 GUI 文件流程只支持手动传递，不显示自动 CLI 选项。旧消息任务保留原协议。

新建交接提供复制短格式，用户把它附在给 A 的工作要求后；安装指令规则后也可由 A 按需输出。无冗余粘贴按钮，用户直接粘贴输入框。

## 处理状态与下一步

显示“等待某 Agent 接收并回复”“某 Agent 正在处理”“等待对方继续”等具体状态，并提供当前等待者对应的复制按钮。短提示指向隐藏 `.relay/context.json`；回执写入同目录 `receipt.json`。

文件事件触发读取，启动/刷新补读。显式 `received/working/done/failed` 回执决定状态，不根据文件变化猜测完成。`done + needs_reply=false` 终态；需要另一方继续必须提供回稿和具体下一步，任务保持进行中。最多四轮，达到上限后停止并提示人工判断；禁止寒暄式往返。

外部文件只复制一份到受管目录，已受管文件复用，不额外生成正文包装与重复结果快照。控制元数据隐藏，正文文件保留真实格式，包括二进制文件。

## Agent 规则与接口

添加/编辑支持新的 lowercase JSON 清单，完整验证后填草稿；`agent setup --manifest` 可直接登记。直写成功不再要求用户重复新增。会话 ID/记录与配置路径、调用方法分别说明。

安装规则必须选择真实宿主指令文件、预览并确认。一行常驻，详细规则按需加载，是否触发依赖宿主。固定指引入口在迁移后刷新。移除仅剥离自有标记区块，保留其他编辑。ZIP 删除无法自动清理，GUI 与 CLI 提供显式移除。

## 连线与高级 CLI

每对一线；单箭头为单向有方案，双箭头为双向有方案，灰色虚线无箭头为双方无方案。绿/红分别表示启用和暂停，双向线可一绿一红。线上不堆叠状态字，悬停查看详情，点击后两个方向分别控制。

CLI 扩充只保存已有方案，不执行或安装桥接。探针分别验证新建和同会话，机器回执和人工可见性确认分离；不会因探针通过宣称真实宿主普遍兼容。原 CLI/MCP 自动消息路线与新手动文件路线独立。

## 存储、通知与刷新

活动任务（含 AwaitingReply）阻止迁移。历史文件与账本复制校验后切换，保留日期沿用；旧站保留为备份，不自动清理。无待迁移记录时明确说明，不能把“迁移校验”当作新迁移成功。失败可解除占用后重试，固定指引刷新，已复制的旧提示需重复制。

通知开关响应选中变化，鼠标、键盘、辅助技术同样保存，失败恢复真实状态，保留其他草稿。关闭全部进程没有后台服务。编辑页遇外部账本更新保留草稿，任务看板可刷新；本窗口操作反馈与外部更新提示分开。

真实宿主、系统通知和显示缩放的人工验证与模拟测试分开记录。完整协议见 [配置与回执](CONFIGURATION_ASSISTANT.md)。
