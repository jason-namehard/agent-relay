# Agent Relay 桌面交互规格

版本：0.1.0-preview.8。Windows 原生 WPF，四个主页面，节点由用户命名，软件不分配角色。

## 页面职责

| 页面 | 内容与操作 |
| --- | --- |
| 任务看板 | 新建交接、请求与回复、当前提示词、处理记录及必要的恢复动作 |
| Agent 管理 | 添加、编辑、移除节点；唯一的节点资料助手；CLI 探针 |
| 连接图 | 有向自动通知能力；按方向启用/暂停；缺方案时引导手工交接或高级扩充 |
| 设置 | 中转站、保留时间、通知、语言配色；高级超时/重试和 CLI 接口扩充 |

旧 Inbox 与审计入口合并到任务详情；适配器不再占主导航。配置助手不重复出现在每个字段和每个页面。主窗口初始 1120×780、最小 900×620，内容纵向滚动。输入控件保证文字垂直完整，长路径可以选择与横向滚动；说明文字换行，列表省略内容提供完整提示。

## 节点与交接

节点名称必填，其余资料可选；内部 ID 自动生成。添加/编辑窗口提供一次整组提示词和回复解析，高级路径字段默认收起。无配置路径也可登记手工节点。

新建交接选择发送方、接收方和正文。生成助手要求 Agent 按固定模板返回上述三项，解析不发送，完成后默认手动复制。自动 CLI 仅在目标新会话能力通过测试且当前方向启用时可选。

任务详情集中展示请求、回复与处理记录。收到、开始、完成和失败均依据明确回报；文件创建、打开或修改不代表完成。CLI 接收回执不等于结果完成。投递未知时检查目标会话后再决定是否重试；取消不终止已经运行的 Agent。

## 连线语义

- 每对 Agent 共用一条线；只有一个方向有调用方案时显示单箭头，两个方向都有时显示双箭头。
- 两个方向均无方案时显示灰色虚线，无箭头。
- 箭头和相邻半段线的绿色表示已启用，红色表示暂停或尚未启用；双向线允许一绿一红。

箭头属于线条几何，线上不重复绘制状态文字。悬停展示两个方向的状态，点击同一条线后，下方分别提供正反方向的控制。A→B 表示有从 A 通过 Relay 传递文件并经 CLI 通知 B 的方案；启用后方可自动调用。页面提供单箭头、双箭头和灰色虚线图例，解释颜色与方向含义。手动复制不受这些开关影响。

## CLI 探针与高级扩充

高级扩充按所选节点导入调用方案。导入仅保存配置，不运行命令；更新方案后须重新测试。方案包含新会话命令、可选同会话命令、依赖、适用版本、来源、许可证和限制。复杂桥接需要已有程序，不自动修改应用源码。

测试 CLI 先展示调用方案与费用提示；真实新会话探针要求短标识和真实会话回执。机器通过后用户去目标软件确认可见并保存。支持续接时在同一探针会话发起第二个标识，分别校验同一 ID 和人工可见性。演示模式不允许实际调用。

正式桌面交接使用新会话命令，同会话测试不自动绑定未来任务到探针会话。一次测试不能保证未来所有调用可见。缺少可用方案仍可手工交接。

## 中转站、通知和刷新

设置允许将中转站迁移到空目录。活动交接、执行或续接通知尚未结束时不迁移。完成文件复制和数据库校验后切换，旧站保留；失败后通过迁移校验重试。修改的是受管路径，外部已复制的提示词需重新生成，CLI/MCP 使用当前地址。

通知使用随包组件，界面只提供开关。关闭全部进程不会启动后台监控；截止时间在下次恢复时处理。任务处理事件仍保存到账本。

外部进程提交账本后，任务看板刷新；编辑页面保留草稿并提示刷新。本窗口操作结果与账本变化提示分开。手动刷新只读取状态，恢复可能处理已批准的投递。

## 外观与协议

六种语言、四套莫兰迪配色与强调色沿用原生资源。界面文案与生成助手跟随语言，协议字段、路径、用户正文和外部诊断保留原文。表单回复全部验证后才填入，用户确认后才保存或创建。

完整模板与协议见 [配置助手](CONFIGURATION_ASSISTANT.md)。底层 CLI/MCP 的适配器、配置迁移与精确会话接口见 [适配器说明](ADAPTERS.md)，与中转站目录迁移分别处理。
