# Agent Relay 桌面交互规格

版本：0.1.0-preview.13。Windows WPF 四页界面，中文使用微软雅黑字体；协议标识和用户路径不做翻译。

| 页面 | 职责 |
| --- | --- |
| 任务看板 | 新建 CLI 任务或文件交接、完成计划、当前等待者、状态记录、取消/删除/人工完成 |
| Agent 管理 | 一个名称、一键直接配置、分区手动字段、CLI 测试及折叠的交接规则 |
| 连接图 | 每对节点一条线，方案方向及独立开关 |
| 设置 | 中转站、保留期、通知、外观、高级 CLI 扩充和移除全部规则 |

## 新建 CLI 任务

任务看板单独提供“新建 CLI 任务”。表单选择发送方及来源会话、接收方、新建或已有目标会话，直接填写工作要求。可指定新会话工作目录，选择 B 处理→A 审阅→B 落实计划；所需方向尚未启用时由用户明确授权。按钮“创建并通过 CLI 发送”进入实际投递，不要求先生成文件或粘贴 JSON。取消不创建任务，也不启动目标。

## 新建文件交接

主要入口是粘贴 `{from,to,file,message?}` 后“解析并创建交接”，也可手动选择节点与已存在文件。存在 CLI 方案时，确认来源及目标会话选择后创建；取消不创建。目标默认新建，可选择已有会话或手动 ID，来源不能从剪贴板自动判断时明确显示未知。已登记方案且发送方向启用时投递，否则手动复制。后续按同 attempt 已绑定 ID 精确续接，失效时明确要求更换。旧消息任务保留原协议。

新建交接提供复制短格式，用户把它附在给 A 的工作要求后；安装指令规则后也可由 A 按需输出。无冗余粘贴按钮，用户直接粘贴输入框。文件交接也提供审阅落实计划，默认不强迫所有任务多轮往返。

## 处理状态与下一步

显示“等待某 Agent 接收并回复”“某 Agent 正在处理”“等待对方继续”等具体状态，并提供当前等待者对应的复制按钮。短提示指向隐藏 `.relay/context.json`；回执写入同目录 `receipt.json`。已接收或处理中时，“下一步”提示等待回执，复制仅作为手动备用操作。

文件投递每轮只提交一次；状态未知或仍在提交时不会自动重复，用户需先查看目标会话。“文件内容预览”展示实际文本内容，二进制文件不作为文本读取。

文件事件触发读取，启动/刷新补读。显式 `received/working/done/failed` 回执决定状态，不根据文件变化猜测完成。明确计划的中间步骤不能由 `done + needs_reply:false` 跳过；缺少回稿或下一步保持当前步骤并报错。无剩余计划时，无待办的 `done + needs_reply:false` 才结束；同时要求后续工作会被拒绝。最多四轮，达到上限后停止并提示人工判断；禁止寒暄式往返。

外部文件只复制一份到受管目录，已受管文件复用，不额外生成正文包装与重复结果快照。控制元数据隐藏，正文文件保留真实格式，包括二进制文件。

任务详情提供取消、删除及人工标记完成。删除先确认，再移除任务和账本历史，保留磁盘文件按保留期清理。人工完成先确认，记录为用户决定，不表示 Agent 已交付完成证据。删除、取消及人工完成不终止已运行的外部 Agent。

## Agent 规则与接口

管理工具栏固定为“新建 Agent、编辑 Agent、删除 Agent、Agent CLI 测试、一键配置”。新建/编辑只有分区手动字段，不提供 AI 配置回复解析。名称只保留一个；内部宿主类型用于适配。可选 CLI 分区分别填写程序、逐行参数、标准输入模板、输出格式与工作目录。

一键配置先复制提示，再弹窗说明粘贴到目标 Agent 新对话。每次生成独立请求与节点目录，执行前读取最新目录；新建不传已有 `--id`，只使用本次登记返回的 ID 导入调用方案。`agent setup --manifest` 直接登记后，不要求用户重复保存。会话记录与配置路径、调用方式分别说明。

安装/移除规则位于选中节点的折叠详情。安装必须选择真实宿主指令文件、预览并确认。一行常驻，详细规则按需加载，是否触发依赖宿主。固定指引入口在迁移后刷新。移除仅剥离自有标记区块，保留其他编辑。ZIP 删除无法自动清理，GUI 与 CLI 提供显式移除。

## 连线与高级 CLI

每对一线；单箭头为单向有方案，双箭头为双向有方案，灰色虚线无箭头为双方无方案。绿/红分别表示启用和暂停，双向线可一绿一红。线上不堆叠状态字，悬停查看详情，点击后两个方向分别控制。

节点另有状态亮点：绿点表示已登记 CLI 方案，悬停说明是否待测试或已验证；红点表示探针失败，灰点表示无方案。节点绿点不等于方向已经启用。

CLI 扩充只保存方案，不启动模型或安装程序。输出适配包含原生 JSON、JSONL 和最终文本，宿主不必输出 Relay 专用回执。探针与人工可见性确认是独立可选诊断，不阻挡已登记并启用方向的投递；准确续接仍需返回相同 ID。任务最终状态由文件回执决定。

## 会话选择

“选择已有会话”只查询指定 Agent，已有缓存立即显示并后台定向刷新；展示标题、活跃时间、cwd、可获取的模型及准确 ID。无默认选中项，不把排序结果当绑定。无发现能力时只提供手动 ID；保存未知 ID 不表示已经验证。首次选择后同任务不再重复询问，任务详情“会话”折叠区可主动更换或明确新建。SQLite 绑定按 task/attempt/turn/agent 保存；旧 attempt 不跨用。执行前重新查宿主存储，不信展示缓存。

调用适配器带有精确来源上下文时自动登记；普通剪贴板入口显示未知并允许一次选择。模型只做工作与回执，不查 Session ID、不修改宿主索引。模型/思考设置默认继承原会话；当前不显示未经宿主支持的统一覆盖选项。

演示模式明确说明不执行真实 CLI，探针禁用不表示失败。在设置可保留当前数据并切换正式使用；常规真实配置直接启动主程序。

## 存储、通知与刷新

活动任务（含 AwaitingReply）阻止迁移。历史文件与账本复制校验后切换，保留日期沿用；旧站保留为备份，不自动清理。无待迁移记录时明确说明，不能把“迁移校验”当作新迁移成功。失败可解除占用后重试，固定指引刷新，已复制的旧提示需重复制。

通知开关响应选中变化，鼠标、键盘、辅助技术同样保存，失败恢复真实状态，保留其他草稿。启动时将已启用的通知程序重新定位到当前发布包；Inbox 新事件按任务合并，覆盖等待、回传、完成及失败，不因普通刷新重复弹出。系统明确拒绝或投递不可用时，显示带标记的应用内右下角提醒；未知投递结果不盲目重发。提示音提供无声音、默认、信息、警告、错误及试听，测试通知不创建任务或调用模型。Windows 最终决定系统横幅是否显示。

关闭全部进程没有后台服务。编辑页遇外部账本更新保留草稿，任务看板可刷新；本窗口操作反馈与外部更新提示分开。

最小化按钮缩到任务栏，保留窗口入口，不进托盘。首次点击 × 询问一次并保存到“关闭时最小化到托盘”；只有 × 按设置隐藏或退出，不重复询问。取消勾选后直接退出；托盘退出始终结束程序。缩到托盘仍监听回执，托盘菜单只有“打开”和“退出”。应用和托盘使用随包图标。

真实宿主、系统通知和显示缩放的人工验证与模拟测试分开记录。完整协议见 [配置与回执](CONFIGURATION_ASSISTANT.md) 与[会话管理](SESSIONS.md)。
