# Agent Relay 0.1.0-preview.12

文件交接现在可以明确选择目标对话，并在同一任务的后续往返中精确续接。来源身份由调用上下文或用户选择提供，不交给模型猜测。

- Session Registry 与现有 SQLite 共用存储，按 task、attempt、turn、agent 保留绑定。创建会话取得真实 ID 后登记，换会话与新 attempt 不会误用旧绑定。
- “选择已有会话”只发现当前 Agent：缓存立即显示、后台定向刷新，不默认选中第一条。发送前重新查宿主存储，会话失效即要求重选，不回退到最近会话。
- 内置 DSH、Zcode、Hermes、WorkBuddy 元数据提供器，读取本机 JSON/SQLite。DSH 利用已有元数据投影显示标题，实际日志文件确认存在，不全量解压正文。
- 来源上下文准确时自动登记；手动粘贴 JSON 无法提供当前来源对话，可明确选择一次。缺少发现能力时可保存手动 ID，但无法核实的会话不自动续接。
- 短探针与界面可见性是可选诊断，不再作为投递硬性前提。会话新建依赖宿主模型配置；已有对话续接默认继承其设置。
- 首次点击窗口关闭询问缩小至托盘或退出，并保存选择。设置可切换，之后不重复询问；托盘退出始终结束程序。

适配命令、模型登录、会话可用性和桌面可见性取决于具体宿主版本。存在存储记录不等于已证明 GUI 可见，模拟续接测试也不等于所有真实宿主均接通。手动文件交接与明确回执继续保留。
