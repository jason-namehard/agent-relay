# Agent Relay 0.1.0-preview.7

连接图每对 Agent 共用一条线，4 个节点由 12 条方向线收拢为 6 条连接线。移除线上重复标签，并提供可直接对照的线型图例：

- 单箭头：只有一个方向有调用方案。
- 双箭头：两个方向都有调用方案。
- 灰色虚线：两个方向均缺少调用方案，无箭头。

箭头及相邻线段的绿色表示启用，红色表示暂停或尚未启用。双向线路可同时呈现一绿一红；点击连线后，正反方向分别设置。手动复制始终可用。

交接提示词现在以用户命名称呼发送方和接收方，节点 ID 只作为技术标识和回调参数。弹窗等待、文件选择、确认和 CLI 探针执行显示各自的操作状态。补齐手动节点和请求内容的本地化。

CLI 能力仍须经机器回执和人工可见性确认，真实模型调用可能产生费用。连接图表示 Relay 内的调用方案与开关状态，不限制宿主的其他通信方式。

Windows 完整解压后运行 `gui/AgentRelay.Desktop.exe`，或使用 `TryDemo.cmd` 查看隔离演示。GUI 与通知包含运行库；CLI/MCP 需要 .NET 10 runtime。
