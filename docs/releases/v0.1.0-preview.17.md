# Agent Relay 0.1.0-preview.17

- 任务看板增加逐行复选框，确认后可批量人工完成或删除；选择两项及以上出现取消全选，刷新仍保留勾选。
- 桥接受阻、发送中、投递未确认和自动能力待验证分别显示，避免把未送达说成等待 Agent 处理。阻塞时提供检查入口，超时保留真实失败原因。
- DSH 桌面桥接通过签名的只读会话接口选择监听，跳过错误端口并在提交前短暂等待就绪。不会自动重发工作请求，诊断不包含签名材料。
- ACP 与 DSH 可共用同一入口续接，能力验证和准确会话要求保留。
- 桥接测试明确提示客户端显示延迟：Zcode 新建与续接可能需重启才能看到，DSH 桌面通常实时显示。未显示不等于调用失败，不应重复运行付费探针。
- 连接方向授权说明启用已暂停或未授权方向，不会自动增加桥接或登录宿主。

历史 DSH 401 的具体物理成因仍未复现。Zcode 暂未找到可靠的免重启刷新接口。真实模型新建、续接和完整工作链仍需单独验证。
