# Agent Relay 0.1.0-preview.6

四个主页面围绕“谁交给谁”组织：任务看板、Agent 管理、连接图和设置。节点名称与角色由用户决定，手动交接不要求宿主配置或 CLI。

- Agent 添加/编辑统一提示词和回复解析，技术字段收进高级区域。
- 新建交接支持生成提示词，再解析发送方、接收方与内容；解析不发送。
- 任务请求、回复和处理记录集中展示，减少重复入口。
- 绿色箭头表示启用、红色箭头表示暂停或尚未启用、灰色无箭头虚线表示缺方案；双向分别控制。
- CLI 新会话与同会话探针分别核验机器回执和用户可见性；演示不发起实际调用。
- 高级 CLI 扩充导入已有调用方案，保存不执行。正式桌面交接创建新会话，不自动复用探针会话。
- 中转站完成复制与校验后切换，旧目录保留；支持失败后的迁移校验。
- 调整输入控件高度、对齐和滚动布局，保证文字完整显示。

探针和自动交接可能消耗目标模型额度。扩充能力取决于目标软件和已实现的桥接方案，并非所有 Agent 均支持；手工交接可独立使用。任务完成仍需显式回报。

Windows 包解压后运行 `TryDemo.cmd` 体验，或运行 `gui/AgentRelay.Desktop.exe` 正式使用。GUI/通知自带运行库；CLI/MCP 需要 .NET 10 runtime。
