# Agent Relay 0.1.0-preview.22

- 持续修改与验收支持选择最终验收方。标准可由用户输入，或先由发起方 Agent 拟定并写回；最终验收方确认通过且无待解决事项后结束任务。
- 验收次数上限可设为 0，表示不设上限。单轮时限和无进展暂停仍然有效；自动调用可能产生模型费用。
- DSH 桌面桥接的凭证预留时钟差；请求接受后若结果查询失败，将状态标为待确认，避免误报为可重发的认证阻塞。
- Zcode 的会话缓存提示说明切换会话等待或保存工作后重启的方法。
- 修复跨平台测试的绝对路径，并保留已存在的 GitHub 发布与文件。

验收结论由所选 Agent 按标准作出，Relay 不独立证明工作质量；真实宿主的表现仍取决于其当前版本和配置。
