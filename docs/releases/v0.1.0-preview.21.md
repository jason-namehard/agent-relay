# Agent Relay 0.1.0-preview.21

- 任务详情显示处理次数、实际验收次数和验收上限，区分交接处理与验收。
- 错误提示可关闭；任务结束或进入下一轮后，过时的异步发送错误不再作为当前错误显示。
- Agent 管理与进行中的任务可重新检测并恢复桥接。DSH 使用只读本机连接检查；其他桥接先检查配置，再由用户确认是否清除失败记录。
- 统一手动和自动传递的界面名称，改进任务选择列的读屏说明。

包含 preview.16 至 preview.20 的桥接、持续验收、多选和手动传递更新。真实宿主的自动投递能力取决于宿主版本、登录状态和配置；配置检查不等于真实会话验证。
