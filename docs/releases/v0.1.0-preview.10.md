# Agent Relay 0.1.0-preview.10

手动协作围绕文件交接与明确回执组织：A 写文件并输出短 JSON，用户粘贴创建任务，再复制短提示给 B；B 按上下文写回执，软件自动更新，不要求用户再次导入已完成回稿。

- 新文件对话框接受 `{from,to,file,message?}`，也可手动选文件；移除冗余粘贴按钮。
- 明确显示等待哪个 Agent、谁正在处理以及下一个复制动作。无需对方继续时结束，需要继续时给真实回稿和具体下一步；最多四轮防止闲聊往返。
- 外部文件只复制一份，已受管文件复用；控制文件置于隐藏 `.relay` 目录，不再制造正文包装文件和重复结果快照。
- 用户确认后可在真实宿主指令文件中安装一行按需规则；详细指引通过稳定入口读取。删除便携软件前可显式移除自有区块，保留其他指令。
- `agent setup --manifest` 允许 Agent 直接填写节点信息，`cli-recipe import` 只保存已有方案；JSON 不会凭空接通 CLI。
- 无待迁移记录时不显示迁移成功；活动任务含等待回传状态会阻止迁移。历史复制后保留原过期日期，旧站备份不自动清理。
- 中文字体改为微软雅黑。

新 GUI 文件交接当前仅手动，原 CLI/MCP 自动消息路线及高级探针保留，旧任务沿用旧协议。真实宿主创建/可见性/续接仍需人工验证；普通测试使用模拟桥接，实际模型调用可能收费。
