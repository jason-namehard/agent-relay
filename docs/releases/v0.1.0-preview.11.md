# Agent Relay 0.1.0-preview.11

Agent 管理以一键直接配置为主，文件交接可以使用已验证且启用的 CLI 路线；手动复制与明确回执仍是同一套任务流程。

- Agent 管理固定五个主按钮：新建、编辑、删除、CLI 测试、一键配置。只保留一个用户名称，手动配置按功能分区。
- 配置提示词每次生成独立请求，读取节点目录，新建不会沿用已选节点 ID；Agent 通过本机接口登记并导入调用方案。
- Relay 适配 DSH、Zcode、Hermes 相关 JSON/JSONL、兼容 JSON 及普通文本输出，目标程序不必输出 Relay 专用回执。具体参数和格式仍需符合安装版本。
- 接收方 CLI 已验证且连接方向启用时，新文件任务及必要回传自动投递；同轮不自动重复。投递状态未知时提示检查目标会话。
- 连接图增加节点状态点，区分方案已登记、探针失败和无方案，悬停显示验证状态。
- 演示模式明确说明真实 CLI 禁用，可保留当前资料转为正式使用。
- 任务支持确认删除记录、取消和人工标记完成；删除保留磁盘文件，人工完成记录用户决定，不验证 Agent 工作或停止外部进程。
- 处理中提示等待回执，JSON 输入错误使用可读说明；“文件预览”改为“文件内容预览”。
- 增加应用图标与 Windows 托盘：最小化收起，“打开”恢复，“退出”关闭；窗口关闭按钮正常退出。

格式适配与模拟测试不代表所有真实宿主均已接通。实际探针可能收费，机器通过后仍需确认宿主会话可见。文件 CLI 投递创建新会话，同会话探针单独验证续接。系统通知和显示缩放仍需人工检查。
