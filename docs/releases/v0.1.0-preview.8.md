# Agent Relay 0.1.0-preview.8

CLI 探针执行期间，主窗口与测试窗口同步显示进度。结束后保留“探针通过，请确认会话可见”或“探针失败，请查看结果”，快速返回的探针也能看清最终状态。

- Agent 列表增加交接情况，标明有无未完成交接。
- 移除有活动交接的节点时，直接给出阻止原因，完成或取消交接后方可移除。
- 通知开关提供可读的无障碍名称与稳定标识，保存后明确显示启用或关闭。
- 通知设置失败时恢复真实开关状态，切换通知保留其他设置草稿。

探针仍需机器回执与人工会话可见性确认；本地模拟桥接不代表真实宿主已接通。实际模型调用可能产生费用。

Windows 完整解压后运行 `gui/AgentRelay.Desktop.exe`；`TryDemo.cmd` 提供隔离演示。CLI/MCP 需要 .NET 10 runtime。
