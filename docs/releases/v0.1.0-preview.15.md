# Agent Relay 0.1.0-preview.15

- 右下角通知重新设计为紧凑圆角卡片，沿用软件配色，标题、图标和关闭按钮共用顶部区域；长正文可滚动，鼠标悬停暂停关闭计时。
- 三种提示音改为独立内嵌声音：清脆单音、上行双音、低音三连。错误音与静音选项保留。
- 修复打开确认窗口或等待操作时，侧栏变成白色矩形的问题。

一键配置登记调用方式，不会同步宿主桌面登录态。WorkBuddy 的真实 CLI 认证与会话续接尚未打通；现有固定交接计划仍最多四轮。多轮反复验收与 CLI 认证适配需要后续改造。
