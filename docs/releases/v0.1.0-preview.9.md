# Agent Relay 0.1.0-preview.9

修复通过读屏或 UI Automation 切换通知时仅改变视觉状态、没有保存的问题。通知开关现在响应选中状态变化，鼠标、键盘和辅助技术使用相同保存逻辑；失败时恢复真实状态并显示原因，其他设置草稿继续保留。

本版本可用于人工试用手动交接。真实 Agent 的 CLI 接入、会话可见性及续接需在具体宿主中确认，本地模拟桥接不代表真实宿主已接通。探针和自动调用可能产生模型费用。

完整解压 Windows 包后运行 `gui/AgentRelay.Desktop.exe`，或用 `TryDemo.cmd` 体验隔离演示。CLI/MCP 需要 .NET 10 runtime。
