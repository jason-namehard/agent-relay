# Agent Relay 0.1.0-preview.1

首个公开预览版：Windows-first 的本机 Agent 任务交接工具，CLI、stdio MCP 和 WPF GUI 共用持久账本。无需云端 Relay 服务。

## 下载后先试

- **Windows x64 完整包**：解压后双击 `TryDemo.cmd`。演示使用虚构 Agent 和预设结果，不需要模型账号，不改现有配置。正式界面运行 `gui/AgentRelay.Desktop.exe`。
- **CLI/MCP 包**：Windows/Linux 需要 .NET 10 runtime；适合命令行和宿主 stdio MCP 接入。

Windows GUI/通知自带运行库。CLI/MCP 在两个包中均需要 .NET 10 runtime。AMQ、Codex CLI 和认证由用户自行提供；源码包不等于应用分发包。

## 能力

- 明确的 A→B 权限、Agent 登记和路径验证。
- 持久任务、显式完成/失败、幂等、审计、受管 Markdown、TTL 和恢复。
- 可选 AMQ 与只读 Codex worker；精确 Codex 会话继续、Windows 通知和复制提示词。
- 七个 stdio MCP 任务工具，以及需审阅批准的 JSON/TOML 配置迁移与回滚。
- Agents、Connections、Inbox、Adapters、Audit、Settings 原生桌面界面。

## 预览版边界

Windows x64 桌面和 Windows/Linux 核心已验证。真实模型执行与原会话继续的实测覆盖当前 Codex；其他宿主可使用手工交接。未知投递不自动重发。取消 Relay 任务不终止宿主进程。

未提供安装器、代码签名、自动更新或系统调度器；所有进程关闭后的截止时间在下次 Recover 处理。微软运行库和通知组件保留各自分发条款，见包内 `DISTRIBUTION_TERMS.md` 与 `licenses/`。
