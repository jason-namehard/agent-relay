# Agent Relay 0.1.0-preview.2

这次更新改善首次接入与桌面易用性。

- 六种界面语言：英语、简体中文、繁体中文、日语、韩语、西班牙语。右上角直接切换，同一数据目录重启后保持。
- 鼠尾草、暖陶、雾蓝、玫瑰灰莫兰迪配色，可自定义强调色；圆角控件和原生导航图标。
- 配置字段旁复制提示词，整组配置助手支持“复制 → Agent 回复 → 粘贴 → 解析代填”。固定 JSON 协议，不自动登记、验证、执行命令或批准迁移。
- 新增回复格式、重复键、大小限制、语言/主题持久化及代填边界回归验证。

下载 Windows x64 包后双击 `TryDemo.cmd`，或运行 `gui/AgentRelay.Desktop.exe`。GUI/通知自带运行库；CLI/MCP 仍需要 .NET 10 runtime。当前没有安装器或代码签名。
