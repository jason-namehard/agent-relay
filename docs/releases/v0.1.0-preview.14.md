# Agent Relay 0.1.0-preview.14

任务看板可直接新建 CLI 任务：填写工作要求、选择双方会话，软件生成上下文并投递。可选接收方→发起方→接收方三步计划，计划中的剩余步骤不会被中途完成回执跳过。

- 运行时始终显示明确标注的应用内右下角任务提醒；Windows 通知中心可用时静默记录，避免重复横幅。
- 通知辅助程序使用当前发布包，失效路径与系统记录失败不会破坏任务回执。
- 设置支持无声、默认、信息、警告、错误声音，提供试听和独立测试通知。
- 最小化按钮保留任务栏窗口；× 按已保存设置进入托盘或退出。
- CLI 公共命令与 GUI 共用会话绑定、投递和工作回执流程，包含直接工作要求、新建/已有会话和显式完成计划。

真实 CLI 仍取决于宿主登录、模型、权限和续接接口；本地模拟测试不代表所有真实宿主均已接通。
