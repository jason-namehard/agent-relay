# Agent Relay 0.1.0-preview.16

任务支持持续修改与验收：作者提交、对方审查、按问题修订，再次审查，通过后由作者接受并记录交付。轮数用完、单轮超时或执行受阻时暂停，可由用户继续、取消或人工结束。

- 增加 ACP 和 DSH 桌面桥接；WorkBuddy 保留手动复制交接。
- 自动投递须由任务明确启用，并有对应新建或续接能力的验证记录；认证、模型、权限或余额受阻时停止自动投递。
- 续接使用绑定的准确会话和原工作目录，沿用会话模型；支持宿主配置检查和逐次缓存用量读取。
- 一键配置引导 Agent 使用内置缓存对齐技能，Zcode 导入方案补齐桌面启动参数。
- 修复切回单次交接的配置残留、无效参数留下半成品任务、回执重复通知和 DSH 桌面认证失败分类。

DSH 桌面桥接依赖运行中的宿主和版本匹配的本机接口，使用前需用户同意读取签名材料到内存；不会保存或显示密钥。低缓存命中率提示可能原因，不能单独证明前缀差异。

本轮验收使用本地模拟，不代表每个真实宿主都已完成新建、续接及自动验收流程的端到端验证。
