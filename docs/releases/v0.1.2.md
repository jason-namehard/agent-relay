# Agent Relay 0.1.2

## 简体中文

- 无法确认中转站位置时，卸载程序保留配置和任务记录；清理失败时显示易读的原因。
- 修复多语言界面任务详情布局，改进读屏支持、长名称展示和演示内容翻译；移除单条交接规则前增加确认。
- 修复安装器构建对 Inno Setup 版本和中文语言文件的依赖。

规则损坏时，清理会停止并保留账本；检查并修复规则后可重新执行清理。真实宿主桥接与高缩放桌面体验需要在相应环境中验证。

## English

- Uninstall preserves configuration and task records when the relay folder cannot be confirmed, and displays readable cleanup errors.
- Fixes the task details layout in multiple languages, improves screen reader labels, long names and translated demo content, and asks for confirmation before removing an individual handoff rule.
- Fixes installer builds across Inno Setup versions and includes the Chinese language files.

If a handoff rule is damaged, cleanup stops and preserves the ledger. Check and repair the rule before retrying. Real host bridges and desktop behaviour at high display scaling require verification in the relevant environment.
