# Agent Relay 0.1.1

## 简体中文

- 调整主题标题栏、确认框、新建 Agent 的配置选择与应用图标。
- 在登记流程说明可选交接规则，并在 Agent 详情展示安装状态和安装、移除入口；写入宿主指令前需要确认。
- Windows 安装目录分为 app 和 docs。通过系统应用列表卸载时，默认保留数据；可选择移除当前站点登记的规则，或清除规则、账本和偏好。账本包含 Agent 配置和任务记录；工作区文件与其他文件保留。

静默卸载保留数据。规则清理只覆盖当前中转站的登记记录；曾使用的其他站点需分别处理。旧版升级不会删除无法确认归属的额外文件。真实宿主和高缩放桌面体验仍取决于具体环境。

Windows 安装版自带运行库，桌面程序、`app\relay.exe` 与 `app\mcp\relay-mcp.exe` 都不需要另外安装 .NET；便携 CLI/MCP 包仍需 .NET 10 runtime。升级已安装的旧版时，新的卸载程序会替换旧入口，旧版遗留的文件不在本次清理范围内。

## English

- Themed title bar, themed confirmation dialogs, a setup chooser when creating an Agent, and a new application icon.
- The setup flow explains the optional handoff rule, and Agent details show whether it is installed with install and remove actions; nothing is written to a host instruction file before you confirm.
- The Windows installer separates `app` and `docs`. Uninstalling from the system app list keeps data by default; it can also remove only the rules registered for the current site, or clear rules, ledger and preferences. The ledger contains Agent configuration and task records; workspace files and other files are kept.

Silent uninstall keeps data. Rule cleanup covers only rules registered for the current relay folder; other sites you used need separate handling. Upgrading from an older release does not delete extra files whose origin cannot be confirmed. Real hosts and desktop behaviour at high display scaling still depend on the environment.

The installer bundles the runtime for the desktop app, `app\relay.exe` and `app\mcp\relay-mcp.exe`, so no separate .NET install is needed; the portable CLI/MCP package still needs the .NET 10 runtime. Upgrading an existing install replaces the old uninstall entry; files left behind by older releases are outside this cleanup.

The latest public download remains the `v0.1.0-preview.22` package; check the release page for the current installer upload.
