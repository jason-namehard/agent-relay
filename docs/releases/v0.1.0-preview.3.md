# Agent Relay 0.1.0-preview.3

这次更新补齐多语言使用流程，并改善连接图、外观设置和操作反馈。

- 六语覆盖完整配置提示词、桌面任务/继续提示词、通知和配置解析错误。JSON 字段、路径、任务原文与外部诊断保持原样。
- 语言与配色选择即保存；自定义强调色提供实时色块预览、就地格式错误及独立保存按钮。新数据目录默认雾蓝，已有偏好保留。
- 单行控件统一为 34 px，表单对齐更一致；导航使用线条图标和选中竖线，长文字及路径可悬停查看全文。
- 4 个及以上 Agent 只绘制明确权限，分离反向曲线并扩大连线点击区域；完整表格仍展示全部方向和默认拒绝。
- Inbox 展示易读事件及已读/未读状态，原始通知信息保留在悬停详情。
- 本窗口操作结果与外部账本提示分开显示；外部更新保留编辑草稿，Home/Inbox 继续通过事件读取状态。

验证：核心 131 项自动回归与 Windows 102 项窗口交互检查通过，依赖许可证检查通过。窗口验证使用隔离配置和模拟任务，不调用模型。

下载 Windows x64 包后双击 `TryDemo.cmd`，或运行 `gui/AgentRelay.Desktop.exe`。GUI/通知自带运行库；CLI/MCP 仍需要 .NET 10 runtime。当前没有安装器或代码签名。
