# Agent Relay 0.1.4

## 简体中文

- 修复手动交接重复判断：只有原始要求和文件内容一致的 JSON 导入才会复用已有任务。更新要求或文件会创建新任务；明确选择文件新建时，即使内容相同也保留独立任务。
- 重复导入运行中的任务时保留当前进度，不重新配置交接方式。
- 修复桥接发送中断后一直显示发送中的问题：单轮超时且未留下投递结果时转为“投递待确认”。检查目标会话后，可以明确允许重发或重新选择会话；不会自动重复发送，合法晚到回执仍可接收。

升级前请先从托盘退出 Agent Relay，再使用相同安装目录覆盖安装。中转站数据独立于程序安装目录；升级前建议备份整个中转站文件夹。

本版通过 335 项核心测试和 309 项 Windows 桌面检查。安装与升级使用独立产品标识及假数据验收；真实宿主桥接、不同显示缩放和正式产品标识下的升级仍需在相应环境中验证。

## English

- Fixes manual handoff deduplication: JSON imports reuse a task only when the original instructions and file contents match. Changed instructions or files create a new task; explicitly selecting a file to create a handoff always keeps an independent task.
- Reimporting a running task preserves its progress and handoff configuration.
- Fixes interrupted bridge sends remaining stuck as sending. Once the turn deadline passes without a delivery result, the turn becomes unconfirmed. After checking the target conversation, you can explicitly allow resending or choose another session. Relay does not resend automatically, and valid late receipts are still accepted.

Before upgrading, exit Agent Relay from the system tray, then install over the existing installation in the same directory. Relay data is stored separately from the program; back up the entire relay folder before upgrading.

This release passes 335 core tests and 309 Windows desktop checks. Installation and upgrade acceptance uses a separate product identity and fixture data. Real host bridges, other display scaling settings and upgrades under the production product identity require verification in the relevant environment.
