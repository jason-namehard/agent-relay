# Agent Relay 0.1.0-preview.18

- 任务看板新增全选，可批量完成或删除；两项及以上显示取消全选。
- 桥接受阻时可复制诊断提示词，交给有本机访问能力的 Agent 排查并修正同一节点配置。任务详情、Agent详情和桥接测试均有入口。
- 诊断提示词每次读取当前状态，给出运行位置和已有配置接口，不复制环境值、命令参数或原始宿主输出；配置先备份，有依据再修改，不自动发探针或继续任务。
- DSH配置检查真实验证签名后的只读会话接口，不调用模型，明确区分历史失败与当前连接状态。
- 后续DSH认证失败附带操作名和非敏感监听诊断，不再丢失定位依据。

当前只读认证通过不代表完整模型工作链已经验证；已有历史阻塞仍由用户确认处理后解除。
