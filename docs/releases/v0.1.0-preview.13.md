# Agent Relay 0.1.0-preview.13

在任务看板直接新建 CLI 任务：填写工作要求，选择来源会话和新建或已有目标会话，软件生成提示并安排执行，不必先让 Agent 写交接文件或 JSON。

- 可选 B 处理→A 审阅→B 落实计划。每个计划步骤都必须完成，不能因中途 `needs_reply:false` 提前结束；回传需要真实回稿和具体下一步。
- `handoff cli-create --manifest` 只保存，加入 `--send --approve` 才发起真实调用；`handoff send --task --approve` 发送已创建任务的当前轮次。
- 最小化按钮保留在任务栏；× 按首次保存的设置缩到托盘或退出，托盘退出始终结束程序。
- 通知程序定位到当前安装包，等待处理、回传、完成及失败等新事件按任务合并，不因刷新反复提醒。
- 设置可选择和试听提示音，并发送不创建业务任务、不调用模型的测试通知。Windows 通知不可用时，可显示明确标注的应用内右下角提醒。

同一任务继续使用已绑定的准确会话；实际创建和续接依赖宿主配置、模型与登录状态，模拟测试不代表每个真实宿主均已接通。Windows 控制系统横幅显示，应用内提醒不会冒充系统通知。
