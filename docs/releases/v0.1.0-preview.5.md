# Agent Relay 0.1.0-preview.5

- 取消批准或关闭审阅窗口后，状态栏明确显示“已取消操作 · 未做更改”，保留当前输入。路径纠正、方向权限、迁移及其他审阅操作使用一致反馈。
- 日语导航标签统一为 `Agent 管理`。
- 增加六种语言的取消反馈、权限保持、登记草稿保持及日语导航回归验证。
- 清理回归按实际文件创建时间构造过期样本。

下载 Windows x64 包后双击 `TryDemo.cmd`，或运行 `gui/AgentRelay.Desktop.exe`。GUI/通知自带运行库；CLI/MCP 需要 .NET 10 runtime。
